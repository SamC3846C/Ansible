# Ansible
This is repo where I am going to keep all my ansible galaxy roles 
| Directory    | Purpose                                        |
| ------------ | ---------------------------------------------- |
| `tasks/`     | **What should Ansible do?**                    |
| `defaults/`  | **What can the user configure?**               |
| `vars/`      | **Internal/static variables**                  |
| `handlers/`  | **What should happen when something changes?** |
| `templates/` | Jinja2 configuration templates                 |
| `files/`     | Static files to copy                           |
| `meta/`      | Role metadata + dependencies                   |
| `tests/`     | Tests for the role                             |
| `README.md`  | Documentation                                  |
